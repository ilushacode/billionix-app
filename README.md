# Billionix App

Фронтенд-часть игры-кликера "Billionix", работающей в Telegram Mini App. Это пользовательский интерфейс, через который игроки взаимодействуют с игровой механикой.

## 📖 О проекте

Этот репозиторий содержит клиентское приложение для игры "Billionix". Оно представляет собой одностраничное приложение (SPA), встроенное в Telegram. Интерфейс оптимизирован для мобильных устройств и обеспечивает плавное взаимодействие с игрой.

Проект создан как pet-проект для изучения разработки интерфейсов для Telegram Mini Apps.

## 🚀 Основные возможности

*   **Telegram Mini App:** Полная интеграция с платформой Telegram (авторизация, интерфейс).
*   **Игровой процесс:** Визуализация кликов, анимация монет, отображение текущего счета и бустеров.
*   **Взаимодействие с сервером:** Отправка запросов к бэкенду для сохранения прогресса и получения данных.
*   **Адаптивный дизайн:** Интерфейс, комфортный для использования на смартфонах.
*   **Анимации:** Плавные переходы и эффекты для улучшения игрового опыта.

## 🛠 Технологии

*   **Библиотека:** React
*   **Сборщик:** Create React App
*   **Стилизация:** CSS
*   **HTTP-клиент:** Fetch API или Axios для связи с бэкендом

## 📁 Структура проекта

```
billionix-app/
├── public/              # Статические файлы (index.html, иконки)
├── src/                 # Исходный код приложения
│   ├── components/      # Переиспользуемые UI-компоненты (кнопки, карточки)
│   ├── pages/           # Компоненты страниц (главная игра, профиль, лидеры)
│   ├── hooks/           # Пользовательские React-хуки (для игровой логики)
│   ├── context/         # Контексты для управления состоянием (например, пользователь)
│   ├── api/             # Функции для запросов к бэкенд-серверу
│   ├── styles/          # Глобальные стили и темы
│   ├── utils/           # Вспомогательные функции (форматирование чисел)
│   ├── App.js           # Корневой компонент
│   └── index.js         # Точка входа в приложение
├── .gitignore           # Список игнорируемых файлов
├── package.json         # Зависимости и скрипты
├── README.md            # Описание проекта
└── ... (файлы конфигурации)
```
